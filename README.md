## Analisi Flare

- [Analisi Flare](index.html): trova i flare nei file FlySight, li misura (carico, rotazione, velocità in orizzontale, efficienza) e dà un giudizio con il consiglio per il salto successivo.
- [Gare PPC](ppc.html): Time, Distance e Speed nella finestra 2500 → 1500 m come FlySight Viewer, con il vento in quota (Open-Meteo).
- [Skyderby → FlySight](skyderby.html): scarica una traccia Skyderby a frequenza piena e la converte in CSV per FlySight Viewer.
